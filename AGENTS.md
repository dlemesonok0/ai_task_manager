# Инструкции для агентов

## Язык

Все проектные документы, рабочие заметки, описания задач, roadmap, backlog и итоговые отчеты пишите на русском языке.

Исключения:
- Код, имена переменных, API-поля, команды, статусы задач и технические идентификаторы можно оставлять на английском.
- Тексты пользовательского интерфейса можно писать на языке, который уже используется в соответствующей части продукта, если задача явно не требует перевода.

## Ветки

Любая feature, fix или нетривиальная проектная правка должна выполняться в отдельной ветке. Не коммитьте напрямую в `master`; создайте отдельную feature-ветку или переключитесь на нее перед изменениями.

## Отслеживание задач

Используйте файлы задач в `docs/tasks/`, чтобы координировать работу агентов:

- `docs/tasks/current.md` содержит задачи, которые готовы к выполнению сейчас.
- `docs/tasks/backlog.md` содержит менее приоритетные или еще не готовые к реализации задачи.
- `docs/tasks/done.md` содержит завершенные задачи и заметки по реализации.

Когда начинаете отслеживаемую задачу:

1. Прочитайте `docs/tasks/current.md`.
2. Измените статус задачи с `todo` на `in_progress`.
3. Держите реализацию в рамках критериев приемки задачи.
4. Если задача слишком большая, разделите ее и перенесите дополнительный объем в `docs/tasks/backlog.md`.

Когда завершаете отслеживаемую задачу:

1. Запустите релевантные тесты или документируйте, почему они не запускались.
2. Перенесите завершенную задачу из `docs/tasks/current.md` в `docs/tasks/done.md`.
3. Укажите дату завершения, краткое описание, затронутые файлы и выполненные проверки.
4. Добавьте последующие задачи в `docs/tasks/backlog.md`.
