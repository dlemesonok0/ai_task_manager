# Текущие задачи

Этот файл хранит задачи, которые уже готовы к выполнению агентами.

## Правила

- Держите задачи достаточно маленькими, чтобы один агент мог выполнить задачу за одну рабочую сессию.
- Завершенные задачи переносите в `docs/tasks/done.md`.
- Если задача разрастается, разделите ее и перенесите дополнительный объем в `docs/tasks/backlog.md`.
- Обновляйте статус перед началом и после завершения работы.

## Статусы

- `todo`: задача готова к началу работы.
- `in_progress`: задача сейчас выполняется.
- `blocked`: задача заблокирована решением, зависимостью или внешним фактором.
- `review`: реализация готова и требует проверки.

Статус: `todo`

- Ошибки API видны пользователю.

### TASK-006: Длительность задач

Статус: `todo`

Цель: дать продукту возможность учитывать, сколько времени занимает задача.

Объем работ:
- Добавить `duration_minutes` в модель задачи и локальный кэш.
- Добавить выбор длительности при создании и редактировании задачи.
- Использовать стандартные варианты: 15, 30, 45, 60, 90 минут.

Основные файлы:
- `backend/services/db_service.py`
- `backend/main.py`
- `frontend/src/App.tsx`

Критерии приемки:
- Пользователь может указать и изменить длительность задачи.
- API задач возвращает длительность.
- Старые задачи без длительности продолжают поддерживаться.

### TASK-007: Auto Schedule v1

Статус: `todo`

Объем работ:
- Добавить API для получения свободных окон в календаре.

- `backend/services/gcal_service.py`

Критерии приемки:

- Ответ содержит короткое объяснение для каждого размещения.
