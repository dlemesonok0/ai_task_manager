# Текущие задачи

Этот файл хранит задачи, которые уже готовы к выполнению агентами.

## Правила

- Держите задачи достаточно маленькими, чтобы один агент мог выполнить задачу за одну рабочую сессию.
- Завершенные задачи переносите в `docs/tasks/done.md`.
- Если задача разрастается, разделите её и перенесите дополнительный объём в `docs/tasks/backlog.md` с новым TASK-NNN.
- Перед переносом задачи из backlog в `current.md` присвоить TASK-NNN и проверить актуальность критериев приёмки.
- Обновляйте статус перед началом и после завершения работы.

## Статусы

- `todo`: задача готова к началу работы.
- `in_progress`: задача сейчас выполняется.
- `blocked`: задача заблокирована решением, зависимостью или внешним фактором.
- `review`: реализация готова и требует проверки.

### TASK-008: Разделение зависимостей на prod и dev

Статус: `todo`

Цель: привести зависимости в порядок — вынести в dev только то, что нужно для разработки и тестирования.

Объем работ:

- `backend/pyproject.toml`

Критерии приемки:

- `uv sync --group dev` устанавливает всё (prod + dev).
- Frontend-сборка (`npm run build`) работает без предупреждений о пропущенных dev-пакетах.
- Все тесты проходят.
